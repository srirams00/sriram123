# Assets Directory for Sriram's Portfolio

This folder contains public assets used across your portfolio.

### 1. Profile Picture (`profile.jpg`)
Place your real professional photo here named:
`profile.jpg`

The portfolio will automatically detect and display your photo with a modern circular/rounded container and warm yellow glow. If `profile.jpg` is not yet added, it gracefully falls back to `profile.svg`.

### 2. Resume PDF (`Sriram_Resume.pdf`)
Place your real resume PDF file here named:
`Sriram_Resume.pdf`

The "Download Resume" button points directly to `/assets/Sriram_Resume.pdf`. If the file is not yet present, the button informs visitors with a clean, professional modal to connect via LinkedIn/Email.
